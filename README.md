# 📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that allows users to manage their stock holdings, retrieve current market prices, calculate investment value and profit/loss, and visualize portfolio distribution.

This project was developed as part of my **Python Development Internship at CodeAlpha**.

---

## 🚀 Features

- Add stocks to your portfolio
- Store stock symbol, quantity, and purchase price
- Fetch current stock prices using `yfinance`
- Calculate total investment
- Calculate current portfolio value
- Calculate overall profit/loss
- Display portfolio data in a structured table
- Visualize portfolio distribution using a pie chart
- Store portfolio information in a CSV file
- Basic input validation and exception handling

---

## 🛠️ Technologies & Libraries

| Technology / Library | Purpose |
|---|---|
| **Python** | Core programming language |
| **yfinance** | Fetch current stock market data |
| **Pandas** | Data processing and DataFrame operations |
| **Matplotlib** | Portfolio data visualization |
| **CSV** | Persistent storage of portfolio data |
| **OS** | File and directory handling |

# Stock Portfolio Tracker

A simple Python internship project that tracks stock holdings, fetches current prices, calculates portfolio value/profit-loss, stores data in CSV, and visualizes portfolio distribution.

## Libraries
- yfinance: fetches stock market data
- pandas: reads and processes portfolio data
- matplotlib: creates the portfolio chart
- csv/os: built-in Python modules for storage and file handling

## Install
```bash
pip install yfinance pandas matplotlib
```

## Run
```bash
python main.py
```

## Features
1. Add stock
2. View portfolio
3. Calculate total investment and current value
4. Calculate profit/loss
5. Display portfolio distribution chart
6. Persist holdings in portfolio.csv
